Compare Last.fm listening

Add two or more Last.fm usernames. Each full scrobble history downloads once and is saved in this browser, so later visits only fetch what's new.

The first download takes a while for big libraries: Last.fm sends 200 scrobbles per request, so 100,000 scrobbles is about 500 requests, a couple of minutes. You can start comparing as soon as two people have finished. If you close the tab, the download picks up where it stopped.

    Add someone else above to compare with. Meanwhile, the Reports tab works for one person.
